ISR (In-Sync Replicas) é a lista de réplicas de uma partition — incluindo o próprio leader — que estão em
dia com os dados confirmados. Apenas followers no ISR são elegíveis para eleição como novo leader em caso de
falha, evitando que uma réplica atrasada assuma e cause perda de dados já confirmados a producers.
